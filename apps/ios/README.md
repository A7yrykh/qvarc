# Кварц — iPhone-приложение гостя (Xcode)

SwiftUI, iOS 17+, Xcode 16 или новее. Сторонних библиотек нет.

## Как открыть

1. Распакуйте `Kvarc.zip` и откройте `Kvarc.xcodeproj` в Xcode.
2. Слева выберите проект **Kvarc** → вкладка **Signing & Capabilities**. Проверьте команду (Team).
   Bundle ID: `ru.qvarcuvildy.guest`. Если Xcode говорит, что такой ID занят, поменяйте на свой.
3. Вверху выберите симулятор iPhone и нажмите **⌘R**.

> Проект написан без компилятора Swift: в облаке, где он собирался, нет Xcode.
> Если при сборке (**⌘B**) будут ошибки, пришлите их текст или скриншот — исправлю.

## Режимы работы

**Демо (по умолчанию).** Сервер не нужен. В приложении видна жёлтая плашка «Демо-режим».
- Вход: любой номер и любой код из 6 цифр.
- Бронь «Коттедж 5 · Семейный коттедж» — пример. Заезд через 2 дня, после 17:00.
- Оплата имитируется, деньги не списываются.
- Код двери — пример, он не связан с замком.
- Прокат — список от владельца. Цены катамарана, сапа и велосипеда взяты с сайта базы, остальное «уточняйте у администратора».
- Номера, апартаменты, коттедж, правила и ответы на вопросы — настоящие, с сайта базы (qvarc-uvildy.ru). Фото грузятся с сайта, нужен интернет.
- Меню ресторана настоящее («Лето 2026»), но демо-заказ не уходит на кухню, а его статусы меняются сами для примера.

**С сервером QVARC.** В файле `Kvarc-Info.plist` впишите адрес в `QvarcAPIBaseURL`:
- сервер на этом же Mac, приложение в симуляторе: `http://localhost:3000`
- iPhone по кабелю или Wi-Fi: `http://<IP вашего Mac>:3000`, например `http://192.168.1.10:3000`
- боевой сервер: только `https://…`

Приложение работает с отдельным гостевым сервером (NestJS). В этом репозитории его пока нет: он лежит в папке проекта `qvarc/backend/`, там же инструкция по запуску. `apps/api` этого репозитория приложение пока не использует. Пока на сервере стоят демо-адаптеры, он сам отмечает демо-ответы, и приложение показывает плашку.

## Что внутри

| Папка | Что там |
|---|---|
| `Kvarc/Core` | цвета и кнопки бренда, форматы дат и сумм, модели данных |
| `Kvarc/Services` | клиент API, Keychain, демо-режим |
| `Kvarc/App` | запуск, состояние приложения |
| `Kvarc/Views` | экраны: вход, главная, регистрация, гости, паспорта, оплата, доступ, ресторан (меню, корзина, заказ, столик), прокат, проживание и «О базе» |
| `Kvarc/Assets.xcassets` | иконка и логотипы из папки «Русификация» |

Как устроено:
- Время везде показывается по базе отдыха (Екатеринбург, UTC+5), а не по часовому поясу телефона.
- Токен входа хранится в Keychain.
- Повторное нажатие «Оплатить» или «Забронировать» не создаёт второй платёж или бронь. Для этого используется ключ идемпотентности.
- Оплата открывается на странице банка внутри приложения. После оплаты банк возвращает гостя по ссылке `qvarc://payment-return`, и приложение проверяет статус платежа.
- Паспорт после сохранения показывается только как «•••• 1234».
- Заказ еды: цену считает сервер по меню. При оплате картой заказ уходит на кухню только после подтверждения оплаты банком.

- Фото номеров названы по типу и номеру: `standart-01`, `komfort-02`, `apartamenty-01`, `semeynyy-kottedzh-03`. Подписи — «Стандарт — фото 1». Список фото — в `Kvarc/Services/DemoProperty.swift` и на гостевом сервере (`backend/data/property-kvarc.json`).
