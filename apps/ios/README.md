# Кварц — iPhone-приложение гостя (Xcode)

SwiftUI, iOS 17+, Xcode 16 или новее. Сторонних библиотек нет.

## Как открыть

1. Откройте `apps/ios/Kvarc.xcodeproj` в Xcode.
2. Слева выберите проект **Kvarc** → вкладка **Signing & Capabilities**. Проверьте команду (Team).
   Bundle ID: `ru.kvarc.guest`. Если Xcode говорит, что такой ID занят, поменяйте на свой.
3. Вверху выберите симулятор iPhone и нажмите **⌘R**.

> Проект написан без компилятора Swift: в облаке, где он собирался, нет Xcode.
> Если при сборке (**⌘B**) будут ошибки, пришлите их текст или скриншот — исправлю.

## Режимы работы

**Демо (по умолчанию).** Сервер не нужен. В приложении видна жёлтая плашка «Демо-режим».
- Вход: любой номер и любой код из 6 цифр.
- Бронь «Коттедж 5 · Семейный коттедж» — пример. Заезд через 2 дня, после 17:00.
- Оплата имитируется, деньги не списываются.
- Код двери — пример, он не связан с замком.
- Прокат — список от владельца. Цены катамарана, сапа и велосипеда — с кварц.рус, остальное «уточняйте у администратора».
- Номера, апартаменты, коттедж и ответы на вопросы — те же, что на сервере QVARC (кварц.рус и документы владельца). Фото в демо-режиме не показываются, они приходят с сервера.
- Меню ресторана настоящее («Лето 2026»), но демо-заказ не уходит на кухню, а его статусы меняются сами для примера.

**С сервером QVARC.** Приложение работает с API этого репозитория (`apps/api`, раздел `guest/v1`, код в `apps/api/src/guest-app`). В файле `Kvarc-Info.plist` впишите адрес в `QvarcAPIBaseURL`, в конце — код объекта:
- сервер на этом же Mac, приложение в симуляторе: `http://localhost:3000/guest/v1/kvarc`
- iPhone по кабелю или Wi-Fi: `http://<IP вашего Mac>:3000/guest/v1/kvarc`
- боевой сервер: только `https://…/guest/v1/kvarc`

Перед первым запуском загрузите сведения о базе и правила: `DATABASE_URL=... npx tsx apps/api/src/cli/import-guest-app.ts kvarc data/kvarc-guest-app.json`.
Вход без SMS для проверки: запустите сервер с `GUEST_TEST_CODE=123456` (любые 6 цифр) и входите с любым номером и этим кодом. SMS при этом не отправляются. В рабочей среде тестовый код запрещён: сервер с ним не запустится. Без тестового кода код входа пишется в журнал сервера (`GUEST_SMS=log`).
Если оплата идёт через тестовый провайдер, приложение показывает плашку «Демо-оплата».

Что уже работает с сервером: вход по коду, брони гостя по номеру телефона, оплата брони через Сбер (предоплата и остаток), сведения о базе с фото номеров, правила проживания, онлайн-регистрация (гости, документы, правила; паспортные данные хранятся зашифрованными, ключ `DOCUMENTS_KEY`). Услуги, ресторан и заказы еды пока возвращают пустые списки; доступ в номер подключается следующим шагом.

## Что внутри

| Папка | Что там |
|---|---|
| `Kvarc/Core` | цвета и кнопки бренда, форматы дат и сумм, модели данных |
| `Kvarc/Services` | клиент API, Keychain, демо-режим |
| `Kvarc/App` | запуск, состояние приложения |
| `Kvarc/Views` | экраны: вход, главная, регистрация, гости, паспорта, оплата, доступ, ресторан (меню, корзина, заказ, столик), прокат, проживание и «О базе» |
| `Kvarc/Assets.xcassets` | иконка и логотипы из папки «Русификация» |

Как устроено:
- Время везде показывается по базе отдыха (Екатеринбург, UTC+5), а не по часовому поясу телефона.
- Токен входа хранится в Keychain.
- Повторное нажатие «Оплатить» или «Забронировать» не создаёт второй платёж или бронь. Для этого используется ключ идемпотентности.
- Оплата открывается на странице банка внутри приложения. После оплаты банк возвращает гостя по ссылке `qvarc://payment-return`, и приложение проверяет статус платежа.
- Паспорт после сохранения показывается только как «•••• 1234».
- Заказ еды: цену считает сервер по меню. При оплате картой заказ уходит на кухню только после подтверждения оплаты банком.

- Фото номеров лежат по категориям: `/rooms/comfort/1.webp` и т.д. Список фото — на сервере (`data/kvarc-rooms.json`), файлы — в `apps/booking/public/rooms`.

## Что пока не подключено

- SMS-провайдер не выбран. Без него настоящий вход по SMS не работает.
- Замки TTLock подключатся, когда владелец даст ключи. Сбербанк подключён в API, нужны тестовые ключи банка.
- Меню пока загружено из PDF «Лето 2026». После подключения iiko меню и стоп-лист будут приходить оттуда, а заказы — уходить на кухню в iiko.
- Пуш-уведомления: в приложении их пока нет.
